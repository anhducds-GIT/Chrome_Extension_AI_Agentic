## Semantic acceptance answers

1. **Why no automatic resend after `SUBMITTED`?** The provider state machine permits retry only while the attempt is `PRE_SUBMIT`/`FAILED_PRE_SUBMIT`. `retryDecision` returns `SUBMITTED_BOUNDARY` for every submitted or later phase. Timeout/ambiguity transitions the same persisted attempt to `OWNER_REVIEW`/`INTERRUPTED`, and checkpoint restore excludes it from pending selection.
2. **Why does output belong to this attempt?** The content adapter freezes URL/image keys and model-response container identities immediately before Send. A result must use a source key absent from that boundary, appear in a newly observed model-response container, remain visible/usable, not be an input, and be unique. “Latest image” or a changed source inside an old container is never sufficient.
3. **How is DOM drift handled safely?** Selectors are layered across ARIA, role, test ID and structure. Unknown composer/send/upload/output state returns an explicit readiness or attribution failure. The adapter never falls back to coordinate/generic first-button clicks; new observed structures must be added with a fixture.
